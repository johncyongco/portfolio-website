# John Christian Yongco - Portfolio Website

A clean, minimalist, and professional portfolio website for an AI Data Operations Specialist.

## Features

- **Modern Design**: Clean, minimalist aesthetic with premium feel
- **Fully Responsive**: Optimized for all device sizes
- **Smooth Animations**: Subtle fade-in effects and hover transitions
- **SEO Optimized**: Proper meta tags and semantic HTML
- **Easy to Edit**: Simple, well-structured codebase
- **Fast Loading**: No heavy frameworks or dependencies

## Sections

1. **Hero**: Name, title, location, and value proposition
2. **About**: Professional summary and background
3. **Core Expertise**: 9 key areas of specialization
4. **Experience**: Timeline of professional roles
5. **Tools & Platforms**: Technical skills and languages
6. **Selected Impact**: Measurable outcomes and achievements
7. **Contact**: Contact information and call-to-action

## Design Principles

- **Minimalist**: Clean layout with strong whitespace
- **Professional**: Understated, credible, premium feel
- **Accessible**: Good contrast and readable typography
- **Consistent**: Cohesive color palette and design system

## Color Palette

- Primary: `#2c3e50` (Charcoal)
- Secondary: `#3498db` (Blue)
- Accent: `#2980b9` (Dark Blue)
- Background: `#ffffff` (White)
- Text: `#333333` (Dark Gray)

## Typography

- **Headings**: Source Serif Pro (serif)
- **Body**: Inter (sans-serif)
- **Icons**: Font Awesome 6

## Technical Details

- **HTML5**: Semantic markup
- **CSS3**: Modern features with fallbacks
- **JavaScript**: Vanilla JS for interactivity
- **No Build Process**: Direct file editing
- **External Dependencies**: Google Fonts, Font Awesome CDN

## How to Edit

### Update Content
1. Open `index.html` and modify text content
2. Update contact information in the contact section
3. Add/remove experience items in the timeline

### Update Styling
1. Edit `style.css` for design changes
2. Modify CSS variables in `:root` for theme colors
3. Adjust spacing and typography as needed

### Update Functionality
1. Edit `script.js` for interactive features
2. Add new sections to HTML and style accordingly

## Browser Support

- Chrome (latest)
- Firefox (latest)

## Performance

- No external JavaScript frameworks
- Minimal CSS (under 20KB)

- Fast loading times
